«Хранители неба» — краткое описание проекта

Команда: Данилов, Самсонова (БСБО-09-23)  ·  Движок: Unity 6 (URP), Input System (new)

1. Идея

Кооперативный сетевой шутер от первого лица на двух игроков, раундовый, с волнами врагов. Светлая аниме-стилистика японской деревни; противники — жуткие чёрные пауки-мимики. Игроки совместно собирают и заряжают «пушку-гарпун», отбиваются от волн и уничтожают вражеский Источник. Гибель обоих игроков — поражение, уничтожение Источника — победа.

2. Сетевая архитектура

  • Сетевая библиотека: FishNet (не NGO и не Photon).
  • Модель авторитета:
    • Серверно-авторитетный геймплей — враги, Источник, пушка, раунд, здоровье игроков считаются на сервере и раздаются клиентам через SyncVar + ObserversRpc/ServerRpc;
    • Owner-authoritative движение игрока — клиент-владелец двигает CharacterController, позиция идёт через клиент-авторитетный NetworkTransform, остальные интерполируют.
  • Режимы запуска (SessionService): Dedicated Server (Linux) — целевой: оба игрока как клиенты (StartServerOnlyAsync на сервере, JoinAsync на клиентах); Host / listen-server (StartHostAsync) — для локального теста.
  • Транспорт: Tugboat (LiteNetLib, UDP), порт по умолчанию 7778.
  • Лобби/комната: на FishNet Broadcast (без отдельного NetworkObject). Лидер = клиент с наименьшим ClientId; «создатель» запускает игру: клиент → RequestStartBroadcast → сервер проверяет и рассылает GameStartingBroadcast.
  • Связь сети и логики: сетевые события сцены → локальный SignalBus через NetworkEventBridge; спавн игроков — серверный PlayerSpawnService, спавн объектов уровня — MarkerBasedSpawnService по маркерам.

3. Основные механики

  • Кооп-пушка (гарпун): заряжается «трупами» убитых врагов (зона CorpseIntake → Weapon.CorpsesLoaded); урон Источнику проходит только когда пушка заряжена.
  • Модули пушки: игроки переносят детали и вставляют в слоты (WeaponModuleSlot); у слота «бюджет хвата» — насевшие враги могут сорвать модуль.
  • Волны врагов: Источник спавнит волны; пауки ползают по любым поверхностям без NavMesh (SurfaceCrawler), прыгают и цепляются.
  • Нокдаун / спасение: враг цепляется за игрока (нокдаун); спасти напарника = убить вцепившегося врага (без «hold-revive»).
  • Ближний бой: ЛКМ (когда игрок не за пушкой) бьёт врагов по видимой позиции.
  • Перенос предметов: серверный захват + клиентский «пин» (PlayerCarry, Carryable).
  • Выпивка / опьянение: зажать E — стэкающееся опьянение, тряска камеры и пост-эффект.
